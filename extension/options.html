yt-dlp Downloader — Settings

Full path to yt-dlp.exe, or just yt-dlp.exe if it is on your PATH.
Runs yt-dlp --update at the path above to upgrade to the latest version.
Where downloaded files are saved. Windows environment variables are expanded by the host.
Enables the Premiere project checkbox in the popup. Point this at a template project containing placeholder media named __YTDLP_VIDEO__.mp4 (on a sequence) and __YTDLP_SUBS__.srt (in the bin). Leave blank to disable. See the README for setup.
Placeholders: {ytdlp} {cookies} {output} {url}. The command is tokenized (shell-style) and run without a shell, so quote paths containing spaces.
Sent as the prompt when you use Download → Claude. It opens Claude Code (Desktop app) in the video's folder; put a CLAUDE.md in your Download-to folder for standing instructions. See the README.
